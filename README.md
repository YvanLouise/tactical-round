# Tactical Round

《战术回合》的游戏介绍网站，由 YvanLouise 制作。页面使用游戏原有插画、实机截图与开场视频，展示回合制塔防玩法和几何世界旅程。

网站地址：<https://yvanlouise.github.io/tactical-round/>

## 本地预览

需要 Node.js 20 或更高版本，无需安装依赖。

```sh
npm start
```

打开 <http://127.0.0.1:4173/tactical-round/>。运行 `npm run check` 检查 JavaScript 语法、本地素材引用、页面锚点、ARIA 关联及结构化数据。

## 页面内容

- 玩法：先塔后敌、资源规划与四阶段回合说明。
- 蓝图：发现、携带、研究，以及四种代表建筑的分工。
- 世界：优莉、费洛与旅行车的旅程，搭配实际大地图画面。
- 模式：战役、挑战、沙盒的规则差异和开放条件。
- 问答：试玩状态、回合规则、存档、平台与画面来源。

实机截图支持点击查看大图；视频和图片弹窗支持 Esc 关闭与焦点恢复。内容依据 2026-10-25 的游戏规则、建筑定义及核心回合、研究、存档实现整理。数值与发行信息变化时同步更新页面；未实装或未公布的内容不作为现有功能宣传。

## 文件

- `index.html`：页面内容、SEO 和语义结构。
- `styles.css`：桌面与移动端样式、减弱动态效果支持。
- `app.js`：实机画廊、玩法介绍切换、手机导航、图片放大及开场视频弹窗。
- `assets/`：展示网站专用素材；来源见 `ASSETS.md`。
- `tools/`：本地预览与素材引用检查。

## 发布

GitHub Pages 使用 `main` 分支的根目录。`.nojekyll` 保留原始静态文件，无需构建。推送到 `main` 后会自动发布。

当前页面介绍开发中的游戏，未提供公开试玩下载。获得正式下载地址后，可在页面末尾添加下载入口。
